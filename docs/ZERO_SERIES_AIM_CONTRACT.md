ボタン名称の「出撃/作戦開始」「飛行を再開/作戦再開」、兵装数、HUDの戦況は説明できる作品差。今回の名称全面統一・外観刷新はしない。追加UIはセンリョウの既存状態欄とゲキチンNormal照準。ファンタジアは横画面・文字200%・回転後に固定カードと衝突する詳細パネルを先に配置する。縦画面・復活表示ではradar優先の最大15000回の探索後、必要なら元の順で残予算を使い再探索する。日本語fontと旧font環境の両方で文字/ボタン寸法・4px間隔・探索合計上限120000を保持する。

相対ドラッグ半径36 CSS px、不感帯8%、操縦指とボタン指の独立所有を保持する。`steeringActive` は実操縦pointerまたは矢印キーの保持中だけtrue（中立sampleへ常時flagを追加しない）。微小入力でも手動操縦中と分かるため、Easy補助で上書きしない。Normalは長押し射撃・縦速度レバー、Easyは自動射撃・自動巡航。矢印/Space/L/W/S/Escの既存意味を維持する。

レバーは上で目標速度上昇、下で下降、releaseで表示だけ中央へ戻し、選んだ目標速度を保持。既存touch v1→v2の明示Save移行、keyboard設定、作品固有storage keyを変更しない。設定保存/取消だけで停止したゲームを勝手に再開しない。

ウチオトセのunexpected lostpointercaptureは安全上の例外：論理動作を止め、全physical pointer/keyが上がってからacknowledgeReleaseし、新しい入力を受け付ける。通常pointerupの後に届くlostpointercaptureは他ownerを失効させない。独立所有を理由に既存release gateを弱めない。

## 3. R2/R3：標的の適格性・保持・補助・射撃

論理60Hzのcontrollerが `FlightTargetLock` を所有する。敵の生存・現在viewへの可視投影・論理遮蔽を先に確認する。keyは種別＋不変ID＋再生成世代。runtime adapterはID/世代を供給し、位置によるfallbackは旧単体fixtureだけ。友軍・旗・基地・死体・削除済みは候補にしない。艦・砲台・地上兵など正規の敵は保持する。

候補順は (1)円内かつ既存射程内、(2)円内だが射程外、(3)円外。各tier内は短辺正規化した中心半径→世界距離→keyの辞書順。同rankを配列順で決めない。held IDが無効なら解除して決定的に再選択。射程は6作品1200m、ゲキチンは従来の1500mを保持する。

同tierで保持を変更するのは、候補の中心半径の改善が **短辺の0.015を厳密に上回る** とき（浮動小数誤差の比較補正1e-12だけ許す）。393px短辺で約5.9 CSS px。これは今回の初期設計値で、ユーザー指定・前回測定値ではない。20cmの距離逆転や等価候補順の変更で揺れない小さい余裕幅を選び、等値/直上/直下を検査する。time holdは追加しない。

手入力中は有効な同tier IDを保持する。より高tierへの変更が必要でも、実操縦pointer/key保持中は補助要求をゼロにし操縦入力を尊重する。逆方向手入力を上書きせず、最大絶対値0.35以上で補助を解除する既存保護も維持。

同tickの補助段階で選んだkeyを、移動後の射撃段階は再検証だけする。Bを新しく選び直して「Aへ補助、Bへ射撃」にしない。選択対象がその間に円外・射程外・遮蔽になればそのtickは撃たず、次tickで再選択する。HUDの役割は次の通りに区別する。カイセン/ファンタジア/ゲキチンのEasy選択強調は保持IDと円内/射程/遮蔽を共有する。ファイトフライト/ウチオトセ/センリョウの赤は既存1500m以内の円内敵接触を表し、1200m自動射撃の可否や保持IDを示さない（友軍の青い注意表示が優先）。マチマモレはUFO・味方機・攻撃中の街の既存markerと白い照準円を表示し、保持IDの強調は持たない。これらの接触/候補markerは操縦・射撃の標的を選び直す処理ではなく、実操縦/自動射撃は全7作品で上記の同key契約を使う。Normalの接触色も固定射線の意味を変更しない。

新たな補助の変化はturn **2.5/s**、climb **1.5/s**、dt=1/60で制限する。マチマモレ/ゲキチンも実進行経路へ接続。対象変更・消失、neutral aim、逆向き手入力は古いpullを即時キャンセルし、新しいpullだけこの上限で増やす（キャンセルをslewで遅らせない）。responseMultiplierは既存1/1.65を維持し2.5/sで追従する。航空/UFO/竜の強度1、艦/砲台/ファンタジア地上敵の既存0.25など作品差を保持する。

再試行/終了/モード変更/操縦機交代でkey・manual・changed・assistTurn/Climb・response履歴を初期化する。停止/再開/入力解除待ちでも古いpullを破棄し、実flightの速度目標と既存水平復帰は変えない。描画FPSを標的保持・補助時間の正本にしない。

## 4. R4/R5：Normal照準と有効カメラ

Normalは銃口/機体前方射線上約500mの固定点を、そのフレームの有効cameraで投影する。敵の距離・生死・射撃pressでは吸着しない。ゲキチンはlocal(0,0,-504.5)を投影し、敵を追尾せず照準DOMのCSS位置だけ直す。弾の向き・機体俯角・武器の定数を変更しない。Easyは従来の中央の照準円と選択標的の意味を保持する。

ゲキチンは `getEffectiveFlightCameraPose` がplayer＋論理collision worldから、名目camera→船体cameraCast(radius1.5)→normal push(2.05)を純計算する。scene、標的投影、照準が同じ関数を使い、rendererの可変stateをsimulationへ逆流させない。沈没の5秒progress/ease・roll・船体位置/回転も共通の `sinkingShipPose` で算出する。実scene.renderのcamera updateをGPUだけ省いて実行し、独立PerspectiveCamera投影との差を検査する。合格要求1 CSS pxに対し数値testは1e-8 CSS px。

論理tickで受理した機体姿勢を同フレームへ描画する。ゲキチンのこの経路へ追加の描画補間はない。マチマモレの既存操縦機交代camera補間18tick（0.3秒）は保持し、その間のEasy補助/自動射撃のみ待機。gateとrender補間の起点を同じ論理tickへ固定し、見えている旧cameraと新機体の判定を混ぜない。Normal手動射撃は変更しない。

## 5. R6/R7：実遮蔽と地形保護

カイセンは既存sweptShipHitTimeの実艦固体でLOSを追加。標的の艦自身は除外し、別の艦/有効な残骸は遮蔽物にする。弾の既存sweepは変更せず、LOSだけ現在poseを使う。ファンタジアはcampaignの実岩とheight fieldのsweepSphereで不可視の敵を除外。投影/距離の安い条件を先に判定し、HUD射撃強調は選択IDに絞ってLOSを再検証する。

センリョウの実battle-flight adapterには既にterrainLineOfSightがあり、実建物を横切るrayで除外を検査する。マチマモレ/ゲキチン/ウチオトセの既存clearLine/world/exposedを維持。全候補に無計画な毎frame重い検査を加えない。低FPSでもcollision worldを省かない。

センリョウEasyは既存 **3秒先・半径40m** の危険予測で、下降入力中も最低climb **0.85** に上げる。標的補助とは別の安全保護で、射撃有無を条件にしない。安全時は介入false。既存 `control-status` へ「地形回避 · 自動上昇中」を表示し、操作説明へ追記、HUD予約寸法に最長文を含める。停止で表示/履歴を解除し、回避そのものを削除しない。

## 6. R8：射撃時の上下ずれの判定

別指射撃、操縦指→射撃への1指持替え、キー射撃、Easy自動射撃は分ける。Normalの同seed・同入力でfire false/trueを実進行12tick×操縦3条件×7作品比較する。敵撃破等の因果が出る前の機体位置・姿勢・基本cameraの一致と、実自機発射8/0を確認する。ゲキチンは有効cameraとNormal照準も独立に検査する。

操縦指を離すとclimb=0へ戻り、既存の中立で水平へ戻る動作が起きる。これをfireがpitchを変えた証拠とはしない。数値/EventTarget/Chromium製品bundle/自動WebKit/実iPhone Safariは別欄に記録する。**実iPhone Safariの申告症状は未解決・未確認**。未再現を理由に姿勢保持へ変更したり、申告を否定しない。
