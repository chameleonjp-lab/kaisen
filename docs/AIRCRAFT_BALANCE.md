# 航空機の威力・距離減衰・HP（2026-10-03）

利用者は自機/僚機/敵機の攻撃への4段階距離減衰、HPの調整、機銃と機関砲のDPSを考慮した調整、関連内容のFaitofuraito同期を依頼した。数値はこの実装で選んだゲーム調整値で、史実性能や利用者指定の数値ではない。

共通実装は `src/aircraft-damage.ts`。全航空機HPは100→80。基礎威力は自機5/25→4/20、僚機3/12→2.4/9.6、敵0.4/0.8→0.32/0.64（機銃/機関砲、HP/発）。近距離のHPと全航空機弾の威力を同じ20%減とし、必要命中数と斉射による撃墜時間を保つ。艦の軽/重対空砲も1/6→0.8/4.8HPへ同じ20%減を適用し、HP80に対する従来の被弾危険を維持する。砲数・発射周期・射界・射程・弾速・重力は変えない。敵航空機の各弾は軽対空砲0.8HPより弱い。HPゲージは現在HP/最大HPを100%へ換算する。

## 4段階

| 銃口から命中点までの実移動距離 | MG倍率/自機HP損傷 | 機関砲倍率/自機HP損傷 |
|---|---|---|
| 0以上200m未満 | 100% / 4 | 100% / 20 |
| 200以上500m未満 | 75% / 3 | 90% / 18 |
| 500以上800m未満 | 50% / 2 | 80% / 16 |
| 800m以上 | 25% / 1 | 70% / 14 |

距離は弾が各固定tickで実際に進んだ3D線分の累積。命中したtickはsweepの最初の接触割合までで加算する。発射後に射手が動いても威力は変わらず、移動中に毎tick倍率を掛け直さない。200/500/800mちょうどは遠い側の段階。第4段階の上端がないことは無限射程ではなく、従来の1.5秒の弾寿命を維持する。MG/機関砲の全陣営から航空機・艦への命中とNormal自機の誤射に適用し、誤射減点は減衰後に実際に失ったHPを用いる。

## 2門・発射間隔・弾倉

- 自機MGは5tick間隔で2発＝毎秒24発。機関砲は15tick間隔で2発＝毎秒8発
- AIはMG17tick間隔で2発＝毎秒120/17発、機関砲57tick間隔で2発＝毎秒120/57発。MGの設定0.28秒は60Hzで0.28333秒となる。自機より長い発射間隔と散布を維持する
- 自機はMG288/機関砲96発。連続射撃では機関砲の最終斉射tick706、MGの最終tick716。その10tickは機関砲が既に空で、両方空になって共通360tickの再装填が始まる
- 次の装填完了/初斉射はtick1076。初斉射tick1から次の初斉射まで1075tick＝17.91667秒。単純な「12秒＋6秒」の18秒ではない。下表の継続DPSは1弾倉の総損傷をこの実周期で割ったもの
- AIは従来どおり弾数制限・6秒装填なし。下表では連続射撃DPSと継続DPSが同じ。これは公平な同一装備という主張ではなく、低威力/遅い発射/有限精度を持つAIのゲーム仕様

HP80に対する自機の必要命中数はMG20/27/40/80発、機関砲4/5/5/6発。両方の2門が全弾命中する最初の斉射からの理想射撃時間は0.25/0.25/0.25/0.5秒。これは飛翔時間を除く。自機速度110m/s時の弾速はMG930m/s・機関砲810m/sなので、同時発射でも着弾は同時ではない。機関砲は単発が重く射撃回数が少ない。遠距離での威力保持も高くし、機銃との差を残す。

実戦の命中率は照準・操縦・散布・相手の移動・射撃可能時間・遮蔽・残弾で変わる。この表へ一律の命中率を掛けた値を実DPSとは呼ばない。単体では実発射tick/弾数/最初のsweep接触/陣営を検査し、最終候補で通常操作の命中/発射数と全滅経路を別途測る。Faitofuraito側も同じmodule/弾倉/装填を同期するが、各作品の実戦結果は分ける。

## 対艦段階へ接続した理由と検査境界

旧4000/2400HPの4艦を航空機銃だけで削る試験操縦では、減衰を付けた空対空調整だけでは時間が伸びた。確定候補のdefault seed/6tick入力/600秒上限ではEasyは艦を全滅させても敵機が残り、Normalは1隻2497.12HPが残った。どちらも全滅合格ではない。これを隠すために検査を短縮/省略せず、既に採用された爆弾/魚雷・砲座抑圧を接続し、艦HP・必要命中数・進入リスクとともに検査してから提出する。旧版画像や旧CIの成功を新しい戦闘の成功へ転用しない。


対艦コアでは装甲船体HPを4000/2400のまま保ち、爆弾1400HP/魚雷2000HPを主手段にした。旗艦は爆弾3発または魚雷2発、他艦は爆弾2発または魚雷2発が直接命中の目安。混合や僚機爆撃で必要な自機投下数は変わる。機銃は船体を削らず、軽/重対空砲60/120HPと上部構造240HPを抑圧する。僚機爆弾は700HP、有限搭載数と6秒補充を使う。詳細はNAVAL_REFERENCE.md。

航空機共通moduleは候補commit `a4390f4dab320c84e94b00fbc4ab0ef1c9aa4951` からFaitofuraitoへ同期した。`aircraft-damage.ts`のSHA-256は `b0a71f4b39aa1adab948ea3f08d99f0ed60e30deb5087992c8f748c9a5fade83`。2026-10-03 07:36 UTCに元作main `037e7914572871f18eb9aa9a41eca4fdae9f3bc7` を確認。元作の時間/勝敗/得点/順位と海のない背景は元作側のまま。両作品の実戦測定を同一視しない。
