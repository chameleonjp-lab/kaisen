# 艦艇・対空射撃の参照とゲーム化

2026-10-02。対象はカイセンの3隻の敵艦（内部検査用の5/7隻にも同じ定義）。航空機モデル、12m級の翼幅、通常カメラ、飛行操作の倍率は変更しない。1 world unit = 1m、時間は秒、船首は艦ローカル -Z。

## 1. 参照対象と確度

大和型の初期装備を着想元にした**架空の主力戦艦**に統一した。263m × 38.9mの船体、前2基・後1基の三連装主砲、前後/両舷の副砲、段状艦橋、中央煙突、舷側対空砲の階層が識別できることを狙う。特定年月日の大和の精密復元や、実在した同型艦3隻の艦隊とは主張しない。

- [大和ミュージアム「数字で見る戦艦『大和』」](https://yamato-museum.com/yamato-data/)で全長263m、最大幅38.9m、46cm三連装3基9門、主砲最大射程42km、発射速度1.8発/分を確認した。この主砲性能値は参照データであり、ゲームの対空射程ではない
- [米海軍NHHC H-044-3](https://www.history.navy.mil/about-us/leadership/director/directors-corner/h-grams/h-gram-044/h-044-3.html)は、四基あった三連装15.5cm副砲のうち二基を撤去して対空装備を増設したことを説明する。1945年の多数の対空砲を初期の副砲配置に足し合わせない
- ゲームの装備表は主砲3×3、副砲4×3、12.7cm高角砲6×2、25mm機銃8×3。**初期のAA搭載基数そのものは今回取得した博物館/NHHCページだけでは一次確認できていない**ため、6/8基の採用を精密な考証済み史実として表現しない。初期装備として知られる13.2mm機銃、艦載水上機、乗員、細部艤装は今回のゲームモデルには実装しない
- 利用者の[戦艦紹介記事](https://milirepo.jp/the-strongest-battleship-during-world-war-ii/)は艦種・規模の方向づけとして参照。記事中のビスマルクの「四連装4基の8門」は内部矛盾があるため装備定義には転載しない

艦橋42m、甲板9m、砲座座標、砲塔外形、砲身の見た目の太さ、舷側平台はゲーム用の近似。資料の図面・写真をゲーム素材へ複製していない。

## 2. 砲の性能出典

[米海軍調査報告 O-47(N)-1, Japanese Naval Guns and Mounts, 1946](https://www.fischer-tropsch.org/primary_documents/gvt_reports/USNAVY/USNTMJ%20Reports/USNTMJ-200F-0446-0523%20Report%20O-47%20N-1.pdf)の銃砲データ表には46cm砲の780m/s、12.7cm/40砲の720m/sがあり、艦用砲架表には大和型用の連装12.7cm砲架がある。PDF検索テキストのft/sとm/s換算には矛盾があるため、ゲームは掲載m/s値を採用し、OCRの全項目が正確とは扱わない。15.5cm副砲の発射性能は今回使用しない。

[米海軍調査報告 O-47(N)-2, AA Machine Guns and Mounts, 1946](https://www.fischer-tropsch.org/primary_documents/gvt_reports/USNAVY/USNTMJ%20Reports/USNTMJ-200F-0524-0618%20Report%20O-47%20N-2.pdf)の25mm節（[読取可能な同報告のOCR](https://www.scribd.com/document/505751188/Japanese-Naval-Guns-AA)）で、初速900m/s、標準220発/分、15発弾倉、弾倉交換を含めて約110発/分、射撃中の動力旋回16°/秒・俯仰12°/秒を確認した。個々の砲身を220発/分の周期で発射し、15斉射ごとの交換待ちを加える。交換待ち4.091秒は約110発/分を再現するゲーム上の平均化で、実測された一定の乗員作業時間ではない。

[米陸軍 TM-E 30-480, 1944, Chapter IX / Antiaircraft Artillery](https://lonesentry.com/manuals/handbook-japanese-military/japanese-antiaircraft.html)の推定性能表は12.7cm砲を約10発/分とする。ゲームはこの周期を採用する。同資料の25mm最大300発/分という戦時推定値ではなく、上記戦後報告の標準220発/分を使う。報告資料は時期、推定、OCRの誤りを含みうるため、掲載値を現代の実測精度で保証しない。

## 3. 実装契約

定義の正本はsrc/naval.tsのNAVAL_WEAPONS / NAVAL_MOUNTS。全21砲座、57砲身の配置・角度を描画と射撃で共用する。主砲9門と副砲12門は対水上用として配置し、この航空機のみの交戦で発射しない。現実の三式弾などによる主砲対空射撃を万能・高速の追尾弾として追加しない。

- 対空砲は14砲座、計36砲身。各砲座が独立して目標ID、方位、仰角、再射撃時計、弾倉残弾、斉射番号を持つ
- 方位/仰角が整うまで有限速度で旋回する。砲座ごとに初期準備時間をずらすが、一つの連装/三連装砲座の準備が整ったときは各砲身から別々の弾を同tickに発射する。一本の太い弾で複数門分を代表させない
- 12.7cmは旋回12°/秒・俯仰10°/秒、25mmは16°/秒・12°/秒。前者は保守的なゲーム設定、後者は上記報告の射撃時値。各AAの方位は正横から前後82°、最低仰角は重AA−8°/軽AA−10°、最大仰角は重AA85°/軽AA80°に制限する。軽AAの−10°はTM-E 30-480の掲載値で、重AAの−8°はゲーム用の保守的設定。低空機が砲座より低いだけで射撃不能にならず、舷外の海面近くまで追うが、自己船体への射線は遮蔽検査で禁止する。方位の詳細な艦上射界は未確認のため、この方位制限を史実の砲架ストッパー角とは呼ばない
- 船体・甲板室・艦橋・煙突・対空砲の円形足場/舷側張出し/支持柱の共有障害物に対し、砲身根元→砲口および初期320mの放物線を検査する。中央構造物を通り抜ける発射、構造物の先に砲口だけ生成する抜け道は認めない
- 重力9.80665m/s²と実時間で進む非誘導弾。照準時だけ現在の位置/速度から短時間の予測を計算し、発射後の目標変更で弾速・方向を曲げない。船速を初速に加える。命中は中央simulationのsweep判定へ渡し、射撃関数が直接HPを減らさない
- 射程を主砲の42kmへ一律にしない。ゲーム交戦制限は12.7cmが斜距離2,800m/相対高度2,600m/弾寿命4.5秒、25mmが1,250m/800m/1.7秒。遠ざかる目標には弾寿命内の解がなければ撃たない。これらは歴史上の最大射程や高射限界ではない
- 空気抵抗、風、艦の動揺、弾種差、信管調定、破片、近接信管、装填員の個別作業は未実装。**短距離のゲーム放物線**であり、42km実弾道や射撃指揮装置の再現ではない
- 照準誤差は重AA0.024rad/軽AA0.033radの決定的なゲーム値。誤差も砲身の目標角へ加え、無限速度で砲身を飛ばさない。HP損傷は重AA6/軽AA1の仮調整値。機銃で艦全体を撃破できる既存のHP制も史実の装甲貫通再現ではない

## 4. 当たり判定、描画、上限

船体の断面列NAVAL_HULL_SECTIONSを描画とsegmentNavalHullEntryで共有する。各区間は甲板/底面/左右舷側/前後端の平面で切った凸多面体で、区間の和集合の最初の進入時刻を判定する。広い船体箱は粗判定にのみ使用し、絞られた船首・艦尾の外側には命中させない。衝突用paddingは各平面を半径分だけ外へ拡張する保守的な近似。平面列は事前生成し、弾ごとの形状生成はしない。shipCollisionBoxesは中央構造物、主・副砲塔、および対空砲の足場/支持構造の包絡箱を返す。円形足場・支持柱の箱は、描画で使う中心/半径/高さから得る保守的な外接箱。描画と安全判定で独立した寸法を持たせない。俯角射撃が隣の足場を通り抜けないこと、砲軸より下の自分の足場で正しい舷外射撃を一律に止めないことを確認する。細い手すり、マスト、砲身は衝突箱に含めない。甲板上面は見える9mに一致し、旧H×0.36の15.12mの見えない屋根も使わない。

描画は静的構造を材質別にまとめ、回転砲塔と全砲身をそれぞれInstancedMesh一つで描く。砲身終端と発射点の一致、別艦間で可動matrixを共有しないこと、factory単位の資源解放を単体検査する。まとめ描きで砲身数や弾数を減らさない。CPU側の構造検査で1艦9描画対象・4,362三角形。これは実GPUのdraw callやFPSの計測値とは区別する。

1艦の1tick最大発射数は36。旋回/弾倉/射界を無視した保守的な生存弾上限は216/艦、7艦で1,512。航空機用余裕256を加えても全体上限2,048未満。毎tickの処理量は砲座21×目標最大5を上限とする。描画FPSや画質で射撃周期・本体tickを変更しない。
