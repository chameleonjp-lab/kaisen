## 4. 構造
TypeScript＋Three.js＋Viteを使い、元作の固定依存を基準にする。物理エンジン、外部AIサービス、ネットワーク対戦、生成APIは不要。
- `types.ts`: team、entity id、航空機、艦、弾、確定イベント、結果を定義
- `flight.ts`: 元作由来の操縦・姿勢・速度・宙返り
- `simulation.ts`: 60Hzの唯一の状態所有者。入力→AI要求→移動→接触→射撃/弾→損傷→全滅/失敗→イベント
- `ai.ts`: 目標配分、追跡/攻撃進入/離脱/再進入、回避、対艦攻撃
- `mission.ts`: 初期配置、艦隊構成、HP、攻撃周期、調整値、ルール版。艦数候補は内部設定に閉じ、未依頼のモード選択を増やさない
- `aircraft.ts` / `ships.ts` / `scene.ts`: 状態を読む描画。見た目の海面波・傾斜で判定位置を変更しない
- `input.ts` / `main.ts`: 操作と画面遷移、固定更新、停止理由、再出撃の所有
- `audio.ts`: 確定イベントから有限の効果音。音の拒否でも視覚情報と本体は維持
- `records.ts`: 採用する場合だけ、作品固有の端末記録。通信層とは分離
- `tests/` / `scripts/`: 純粋ロジックとブラウザ検査。公開ビルドに状態改変用の試験入口を入れない

## 5. AI・戦闘・艦隊
- 味方は2機を迎撃寄り、2機を対艦寄りに仮配分。攻撃者が同じ標的へ集中しすぎないよう安定したid順と担当数で配分し、標的死亡時のみ即座に再選択する。
- 敵機は生存中の自機/僚機を狙う。正面からの攻撃後は離脱し再進入。味方/敵とも未来入力を見ず、同じ速度/旋回の限界で動く。
- 判断は固定tickの有界な間隔、移動は毎tick。描画FPSや実CPU時間でAIの強さを変えない。初期AI9機、180秒以降は最大AI12機。navmeshやWorkerを導入しない。
- 艦は船体、甲板、艦橋、主砲、煙突の読めるシルエットを手続き生成。U07追加改修により全艦を263m級へ統一し、武装の構成と仮設定をNAVAL_REFERENCE.mdへ記録。実在艦の精密再現は主張しない。
- 艦は低速で航行し、対空砲は射程・再射撃待ち・弾速を持つ実弾。照準は発射時点で確定、発射後の追尾や直接HP減算にしない。
- 航空機は相対移動sweep、艦は描画と同じ細くなる船体断面/上部構造boxへ線分判定。複数部位でも弾1発の命中は最初の1回のみ。
- 撃破した敵は目標から直ちに除外し、炎・煙・沈没は別の有限寿命。最後の撃破演出の終了をクリア計時の条件にしない。
- 自機の海面衝突は実高度へ対応。1,200m制約は削除し、低空警告と海面衝突の明確な表示へ置換する。
