# 航空機の弾道とEasy発射補正の同期

利用者がFaitofuraitoの「見やすい弾道」「弱めたEasyの弾補正」をカイセンにも適用すると明示したため、[元作PR13](https://github.com/chameleonjp-lab/faitofuraito/pull/13)の `d567ec92ab4cdd7a0c463d65554eec561105d69f` を移植する。2026-10-03 09:51 UTCにPR13の本人によるマージ `3c63221d020874555cd152a72ff3678425d977a4` を確認した。承認前の「Easy補助をそのまま」の記録を、この新指示が発射方向だけ更新する。元作のPR状態や測定をカイセンの合格とは呼ばない。

## 共通にした仕様

- 自機Easyは、1.5秒以内の直進予測が機首から0.16rad以内という従来の門を維持。その予測角の25%、最大0.02radだけ発射時に補正。以後の弾は曲がらず、命中判定・4段階損傷・弾速・弾数・装填を維持
- `applyEasyShotCorrection`を自機Easyのみに適用。Normalは砲軸、敵/僚機は従来の予測と散布を使う。艦のAA・爆弾・魚雷へ航空機補正を流用しない
- カメラ/飛行/原機体のファイルは旧候補2d45214とbyte一致。`getFlightAssist`の操縦補助も同じ。Easyの自動射撃範囲1.2km・円内条件は変わらない
- 航空機MG/機関砲はThree公式LineSegments2の画面幅1.5px芯/2.5px暗縁、45msの速度方向の尾。生まれてからの弾齢で尾を切り、銃口の後ろに線を生まない。友軍の黄色系/敵の橙赤系という区別を保ち、RGBを元作共通の[1,.7,.14]/[1,.24,.07]へ合わせる。深度判定で艦や機体を透かさない。AAは従来の線と点を維持
- typed bufferを共有する2pass、最大2048区間、停止/再出撃では使い回す。ロード中に両materialを一度描画してから作戦を開始。新しい画像素材・外部読込・依存はない
- 共通の弾寿命をmissionの定数へ移し、表示とシミュレーションの不一致を防止。ルールIDはair-sea-7へ進め、旧補正での記録と混ぜない

## 検査の区別

角度の25%/上限/門/0角、Normalの砲軸、AIの全予測、発射後の非誘導を単体で確認。表示は出生/45ms/陣営/AA除外/上限/解放/画面幅/深度を検査する。DPR3と縦横の実WebGL画像、Easyの手動先読み・対艦全滅は最終候補CIで別に確定する。

同じ6seed×縦横の通常ミッションの無操作比較では、旧/新とも12条件すべて航空機撃墜0。4.5〜5.2秒で艦/海面へ衝突する既存カメラ・操縦補助の条件なので、この試験から命中率低下の量は算出できない。元作の108→0という別世界の数値を転記しない。実戦の実発射/損傷はAIRCRAFT_BALANCE.mdと再実行可能なJSONで記録し、人の操作性と区別する。

CI26の旧補正による23/24passは新補正への合格流用対象外。Easy実入力が中央値15tick間隔/受付7tick遅延になる実記録を保存し、旧試験操縦の過大なヨー入力の振動を回帰へ取り込む。失敗した600秒条件・通常のHP/敵補充/全滅条件を保持し、Easy完走をブラウザ一覧の先頭へ移す。全件と25件のブラウザを最後にまとめて実行する。

## 試験操縦の修正と独立した入力例

CI26の遅延は要求間隔中央値15tick、受付まで7tick。以前の高いゲインを毎回使うと左右反転を続けるため、短い間隔では保持時間に合う応答を使い、150msを超える観測間隔を一度確認したら減衰応答を保つ。瞬間の間隔ごとに強弱を交互へ切り替えない。Normalの応答はそのまま。

Easyの試験操縦はMGが残っている間は+820m/s、残る機関砲には+700m/sで先読みする。損傷進展のない目標を替えた直後に距離評価だけで元へ戻さない。爆撃中は低い可視敵への操縦補助を、通常の小さい上向き入力で打ち消す。最後の艦を倒した後は、衝突コースでない航空機にも250mで離脱を反復していた手順を終了する。実衝突予測による回避、80m/低高度の離脱を維持する。

修正後の関連24件はpass。Easyは6tick196.10秒、6/7tick177.03秒、過去不均等入力359.78秒、CI26の実要求/受付列417.63秒で全滅。Normalの6/7/12tickと既存CI19/20/21列も全滅。全て実HP/補充/通常入力で、時計や結果を注入しない。ただし詳細な世界状態を知る自動操縦の到達性であり、通常の人が同じ時間で遊べるという主張ではない。

独立した空戦fixtureでは、開始後は敵位置を一度も読み取らず「横入力0.6を20tick、その後離す」という固定操作だけで4秒に24発・3命中・22HP損傷。敵AIと通常の弾判定は動く。艦隊と他機を離した隔離条件で、通常ミッション完走/人の試遊/実機の証明とは区別する。`easy-shot-correction.test.ts`で再現する。

独立レビューは補正/AIとNormalの不変/深度/弾齢/DPR/解放を対象に15関連pass、重大指摘なし。実画面・通常ミッション完走はこのレビューの合格範囲に含めず、最後の25ブラウザで確定する。

## CI27後のNormal受入

CI27でEasy実全滅と弾道表示はpass、Normalだけ艦全滅後の空戦が600秒を超えた。検査操縦の250m離脱を艦残存中だけに限定する条件をNormalへも揃え、飛行/カメラ/弾補正/攻撃値を維持。正面衝突回避と80m/低高度退避は残る。Normalの6/7/12tickは225.0333/277/275.2333秒、既存遅延列も全滅。受付観測値と実反映tickの違いがあったため、開発用の正確な消費入力記録を追加し、実ブラウザ結果を次のheadで確定する。詳細と未確認項目はVERIFICATION.md。
