# カイセン

自機1機と4機の僚機で、初期敵機5機とアイオワ級を参考にした戦艦4隻をすべて撃破するブラウザ向けタイムアタック。
ファイトフライトの航空機モデル、操縦、カメラを引き継いでいます。

## どんなゲーム？

戦闘機を操縦して、空の敵航空隊と海上の戦艦を同じ戦場で相手にする、1人用の3D空海戦ゲームです。4機の僚機と協力し、空戦では機銃・機関砲、対艦戦では爆弾・魚雷を使い分けて作戦完了を目指します。

- **目標**：敵機と4隻の戦艦をすべて撃破すること。敵機には増援が来るため、撃墜数だけでなく現在の残り敵数を見ながら進めます。
- **挑戦する面白さ**：低空から魚雷を投下するか、爆弾で攻めるか。対空砲火や海面との衝突を避けながら、攻撃の順番と進入方向を選びます。
- **終わり方**：全敵を倒すとクリア。自機のHPがなくなる、海面や敵・艦の残骸に衝突すると作戦終了です。速さだけでなく攻撃への貢献や被害もスコアに影響します。
- **はじめてなら**：自動射撃・巡航速度の補助がある「イージー」。射撃と速度を自分で管理したい場合は「ノーマル」を選べます。

## 遊び始めるには

[ブラウザでカイセンを開く](https://chameleonjp-lab.github.io/kaisen/)

ホームで難易度を選び、「ルールと操作方法」を確認してから出撃してください。スマートフォンでは画面のドラッグ、PCでは矢印キーで操縦します。細かなキー割当や兵装の使い方は下の「操作」にまとめています。オンライン対戦・オンラインランキングはありません。

このREADMEのルール説明はリポジトリのソースに対応します。公開ページが同じ版とは限らないため、公開状況は[配備記録](docs/DEPLOYMENT.md)と実際のゲーム内説明も確認してください。実機での動作・操作感の確認状況は[検査記録](docs/VERIFICATION.md)で区別しています。


## 操作
- ホームでイージー/ノーマルを選択。初期はイージー、再出撃でも選択を保持します
- イージー: カメラ/操縦補助と照準円内への自動射撃・巡航速度を維持。弾の発射補正は弱め、見える弾道を目安に相手の少し先へ向けます
- ノーマル: 実際の機銃方向へ照準を合わせ、射撃を長押し。上下の速度レバー（離すと中央へ戻り、調整した速度を保持）で速度を調整します
- スマートフォン: 画面を触れた位置からドラッグして旋回・上昇・下降。右下の宙返りで回避
- PC: 矢印キーで操縦、Lで宙返り、Escで停止/再開。ノーマルはSpaceで射撃、W/Sで加速/減速。両モードでZは爆弾、Xは魚雷
- 元作の相対ドラッグ、速度ごとの旋回、宙返り、カメラを再利用。艦の対空弾は重力に従い、発射後は追尾しません
- 自機撃墜・敵との衝突・海面接触で失敗。敵機と艦の両方を全滅させるとクリア
- 弾切れになると6秒で自動再装填。照準円の外周ゲージと残秒で表示します
- 作戦時間40秒ごとに、生きている敵機が5機になるまで不足分を補充。空海を全滅した時点で即クリア。復活敵を自機で撃破すると15HP回復（最大80まで）。敵機は初期・増援を区別せず、自機の先着5機までが得点対象です
- 撃墜された僚機は、それぞれ40秒後に復帰します。自機の復活はありません。僚機1〜4の被撃墜・復帰・敵機撃墜を短く通知し、結果画面にも記録します
- 機銃/機関砲は敵機と艦の対空砲・上部構造へ。装甲船体には爆弾/魚雷を使用します
- 爆弾2発、魚雷1発。各兵装は使い切ると6秒で補充。爆弾の予想落下点を海/甲板への進入の目安にします
- 魚雷は高度20〜80mを目安に、450km/h以下で水平に近い姿勢から投下。入水後80mの航走で起爆可能になり、早すぎる命中や強すぎる入水は不発になります
- 航空機弾は実飛翔距離200/500/800mで4段階に減衰。機関砲は重く、機銃より遠距離の威力を維持します
- 艦はゆっくり航走し、撃沈後も沈むまで残骸へ衝突します。波・航跡・砲塔・煙火・水柱と、距離/方向のある効果音を表示します
- ノーマルでは自機の弾が味方にも命中します。僚機から味方への誤射は従来どおり保護します。誤射損傷は仮値で1HPごと-10点、味方撃墜は追加-1500点
- 照準円は通常白、敵が入ると赤、味方が入ると青。ノーマルの砲軸照準は見やすい大きさと固定の投影距離に調整
- ホーム・停止・結果の「操作設定」で、タッチ配置・大きさ・不透明度とPCのキー割当を保存できます
- 停止・非表示中は時間・再装填・増援待ちを加算せず、操作で再開します

ホームと一時停止画面の「ルールと操作方法」では、使っている入力に応じた説明だけを確認できます。画面上の撃墜/撃沈数は編隊全体の累計で0から増え、現在の残り敵数も併記します。

## 開発
Node.js 24、npmを使用。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

開発サーバー: http://127.0.0.1:4176/

```sh
npx playwright install chromium webkit
npm run test:browser
```

ブラウザ検査の画像と状態記録は test-results/ に保存されます。GitHub ActionsはPRの検査と、承認したmainコミットの手動Pages配備を分けています。公開手順と検証は [配備記録](docs/DEPLOYMENT.md) を参照してください。
