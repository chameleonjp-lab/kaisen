# カイセン

自機1機と4機の僚機で、初期敵機5機と大型戦艦4隻をすべて撃破するブラウザ向けタイムアタック。
ファイトフライトの航空機モデル、操縦、カメラを引き継いでいます。

## 操作
- ホームでイージー/ノーマルを選択。初期はイージー、再出撃でも選択を保持します
- イージー: 現在の照準補助・照準円内への自動射撃・巡航速度を維持
- ノーマル: 実際の機銃方向へ照準を合わせ、射撃を長押し。加速/減速ボタンで速度を調整します
- スマートフォン: 画面を触れた位置からドラッグして旋回・上昇・下降。右下の宙返りで回避
- PC: 矢印キーで操縦、Lで宙返り、Escで停止/再開。ノーマルはSpaceで射撃、W/Sで加速/減速
- 元作の相対ドラッグ、速度ごとの旋回、宙返り、カメラを再利用。艦の対空弾は重力に従い、発射後は追尾しません
- 自機撃墜・敵との衝突・海面接触で失敗。敵機と艦の両方を全滅させるとクリア
- 弾切れになると6秒で自動再装填。照準円の外周ゲージと残秒で表示します
- 作戦時間40秒ごとに、生きている敵機が5機になるまで不足分を補充。空海を全滅した時点で即クリア。復活敵を自機で撃破すると15HP回復（100まで）、得点加算はありません
- 撃墜された僚機は、それぞれ40秒後に復帰します。自機の復活はありません
- ノーマルは味方にも命中します。誤射損傷は仮値で1HPごと-10点、味方撃墜は追加-1500点
- 照準円は通常白、敵が入ると赤、味方が入ると青。ノーマルの砲軸照準は見やすい大きさと固定の投影距離に調整
- ホーム・停止・結果の「操作ボタンの配置」で、モードごとの位置・大きさ・不透明度を保存できます
- 停止・非表示中は時間・再装填・増援待ちを加算せず、操作で再開します

## 開発
Node.js 24、npmを使用。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

開発サーバー: http://127.0.0.1:4176/

```sh
npx playwright install chromium
npm run test:browser
```

ブラウザ検査の画像と状態記録は test-results/ に保存されます。GitHub ActionsはPRの検査と、承認したmainコミットの手動Pages配備を分けています。公開手順と検証は [配備記録](docs/DEPLOYMENT.md) を参照してください。

## 今回の仕様と検査状況

公開試遊のフィードバックを受け、4隻・艦HP4倍、敵と僚機の復活、誤射減点、操作設定、入力復旧、照準と死亡原因、プロペラ音量を更新しています。依頼ごとの対応は [依頼追跡](docs/REQUESTS.md) に記録します。イージーの照準補助は変更せず、ノーマルでは補助のない手動射撃を使います。今回の変更の検査状態・公開済み版との区別は [検査記録](docs/VERIFICATION.md) が正本です。

263m×38.9mの戦艦、砲台別の射界/照準/装填、低空用対空機銃、機体姿勢を含む海面接触を追加しました。史実の参考値とゲームの仮設定は [武装の出典と限界](docs/NAVAL_REFERENCE.md)、最新の検査対象は [検査記録](docs/VERIFICATION.md) を参照してください。

[今回の公開基点CI](https://github.com/chameleonjp-lab/kaisen/actions/runs/37084934703)は107単体・build・ブラウザ19件が合格した版です。これを今回の追加修正の合格証拠へ流用せず、最新候補を再検査します。

### 前版の記録（今回の改修の合格証拠とは別）

[コア実装の確定CI](https://github.com/chameleonjp-lab/kaisen/actions/runs/36972581897)で56単体検査・build・ブラウザ10件が合格。実タッチの検査操縦で35.50秒のクリアを確認しました。代表本編画像は独立目視済みです。実機性能・音の実聴・本人による操縦感の採用は未確認です。

[公開中のカイセン](https://chameleonjp-lab.github.io/kaisen/) はmain 1950788の版です。今回の追加フィードバックは検査・Draft PRの段階で、まだ公開していません。公開手順は [配備記録](docs/DEPLOYMENT.md) を参照してください。
