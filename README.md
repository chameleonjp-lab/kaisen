# カイセン

自機1機と4機の僚機で、初期敵機5機と大型戦艦3隻をすべて撃破するブラウザ向けタイムアタック。
ファイトフライトの航空機モデル、操縦、カメラを引き継いでいます。

## 操作
- スマートフォン: 画面を触れた位置からドラッグして旋回・上昇・下降。右下の宙返りで回避
- PC: 矢印キーで操縦、Lで宙返り、Escで停止/再開
- 照準円内の敵機・艦へ自動射撃。自機の射撃は元作の操作感を維持。艦の対空弾は重力に従い、発射後は追尾しません
- 自機撃墜・敵との衝突・海面接触で失敗。敵機と艦の両方を全滅させるとクリア
- 弾切れになると6秒で自動再装填。照準円の外周ゲージと残秒で表示します
- 3分で敵3機が一度復活。復活前に全滅すれば即クリア。復活敵を自機で撃破すると15HP回復（100まで）、得点加算はありません
- 停止・非表示中は時間・再装填・増援待ちを加算せず、操作で再開します

## 開発
Node.js 24、npmを使用。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

開発サーバー: http://127.0.0.1:4176/

```sh
npx playwright install chromium
npm run test:browser
```

ブラウザ検査の画像と状態記録は test-results/ に保存されます。GitHub Actionsは読み取り権限のPR検査だけを行い、配備しません。

## 今回の仕様と検査状況

263m×38.9mの戦艦、砲台別の射界/照準/装填、低空用対空機銃、機体姿勢を含む海面接触を追加しました。史実の参考値とゲームの仮設定は [武装の出典と限界](docs/NAVAL_REFERENCE.md)、最新の検査対象は [検査記録](docs/VERIFICATION.md) を参照してください。

[追加改修のCI](https://github.com/chameleonjp-lab/kaisen/actions/runs/37008385156)で94単体・build・ブラウザ12件が合格。通常タッチ操縦の全滅、3分後の3機復活、再装填リングの停止/完了を実経路で確認し、進入/装填/結果の実画像を目視しました。仮設定と実機未確認は検査記録に明記しています。

### 前版の記録（今回の改修の合格証拠とは別）

[コア実装の確定CI](https://github.com/chameleonjp-lab/kaisen/actions/runs/36972581897)で56単体検査・build・ブラウザ10件が合格。実タッチの検査操縦で35.50秒のクリアを確認しました。代表本編画像は独立目視済みです。実機性能・音の実聴・本人による操縦感の採用は未確認です。

公開プレイURLはまだ確認されていません。配備はこの実装作業に含めていません。
