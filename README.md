# カイセン

自機1機と4機の僚機で、初期敵機5機と大型戦艦4隻をすべて撃破するブラウザ向けタイムアタック。
ファイトフライトの航空機モデル、操縦、カメラを引き継いでいます。

## 操作
- ホームでイージー/ノーマルを選択。初期はイージー、再出撃でも選択を保持します
- イージー: カメラ/操縦補助と照準円内への自動射撃・巡航速度を維持。弾の発射補正は弱め、見える弾道を目安に相手の少し先へ向けます
- ノーマル: 実際の機銃方向へ照準を合わせ、射撃を長押し。加速/減速ボタンで速度を調整します
- スマートフォン: 画面を触れた位置からドラッグして旋回・上昇・下降。右下の宙返りで回避
- PC: 矢印キーで操縦、Lで宙返り、Escで停止/再開。ノーマルはSpaceで射撃、W/Sで加速/減速。両モードでZは爆弾、Xは魚雷
- 元作の相対ドラッグ、速度ごとの旋回、宙返り、カメラを再利用。艦の対空弾は重力に従い、発射後は追尾しません
- 自機撃墜・敵との衝突・海面接触で失敗。敵機と艦の両方を全滅させるとクリア
- 弾切れになると6秒で自動再装填。照準円の外周ゲージと残秒で表示します
- 作戦時間40秒ごとに、生きている敵機が5機になるまで不足分を補充。空海を全滅した時点で即クリア。復活敵を自機で撃破すると15HP回復（最大80まで）、得点加算はありません
- 撃墜された僚機は、それぞれ40秒後に復帰します。自機の復活はありません。僚機1〜4の被撃墜・復帰・敵機撃墜を短く通知し、結果画面にも記録します
- 機銃/機関砲は敵機と艦の対空砲・上部構造へ。装甲船体には爆弾/魚雷を使用します
- 爆弾2発、魚雷1発。各兵装は使い切ると6秒で補充。爆弾の予想落下点を海/甲板への進入の目安にします
- 魚雷は高度20〜80mを目安に、450km/h以下で水平に近い姿勢から投下。入水後80mの航走で起爆可能になり、早すぎる命中や強すぎる入水は不発になります
- 航空機弾は実飛翔距離200/500/800mで4段階に減衰。機関砲は重く、機銃より遠距離の威力を維持します
- 艦はゆっくり航走し、撃沈後も沈むまで残骸へ衝突します。波・航跡・砲塔・煙火・水柱と、距離/方向のある効果音を表示します
- ノーマルでは自機の弾が味方にも命中します。僚機から味方への誤射は従来どおり保護します。誤射損傷は仮値で1HPごと-10点、味方撃墜は追加-1500点
- 照準円は通常白、敵が入ると赤、味方が入ると青。ノーマルの砲軸照準は見やすい大きさと固定の投影距離に調整
- ホーム・停止・結果の「操作ボタンの配置」で、モードごとの位置・大きさ・不透明度を保存できます
- 停止・非表示中は時間・再装填・増援待ちを加算せず、操作で再開します

## 開発
Node.js 24、npmを使用。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

開発サーバー: http://127.0.0.1:4176/

```sh
npx playwright install chromium
npm run test:browser
```

ブラウザ検査の画像と状態記録は test-results/ に保存されます。GitHub ActionsはPRの検査と、承認したmainコミットの手動Pages配備を分けています。公開手順と検証は [配備記録](docs/DEPLOYMENT.md) を参照してください。

## 今回の仕様と検査状況

追加依頼の僚機通知、航空機の武器別距離減衰とHP調整、空対艦兵装、移動する大型艦の損傷・沈没、波/光/砲撃/空気感/空間音を実装しています。依頼全体と未確認の証拠は [追加採用分の追跡](docs/NEXT_RELEASE.md)、武器調整は [航空機DPS](docs/AIRCRAFT_BALANCE.md) と [対艦兵装](docs/NAVAL_REFERENCE.md) へ記録しています。数値はゲーム調整値で、史実兵器の精密再現とは区別します。

[公開中のカイセン](https://chameleonjp-lab.github.io/kaisen/) はmain c63bff8の版です。今回の追加機能は未公開の作業候補です。旧版CIの成功を新候補へ流用せず、[検査記録](docs/VERIFICATION.md) と提出PRの完全SHA/Checksで確認します。公開手順は [配備記録](docs/DEPLOYMENT.md) を参照してください。
